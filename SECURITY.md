# Security

This repository is a personal website (Hugo), its two form-handling functions
(`functions/`) and the admin portal that edits it (`admin/`).

## Reporting a problem

If you find a vulnerability, please email **contact@loconsole.eu** rather than
opening a public issue. Include what you found, where, and how to reproduce it.

I will acknowledge a report within a few days. This is a one-person project, so
there is no bounty and no formal SLA, but I take reports seriously and will credit
you if you like.

## What is in scope

- The public site at lorenzo.loconsole.eu, including the contact and newsletter forms.
- The admin portal at admin.loconsole.eu (sign-in is by passkey only).
- The code in this repository.

Please do not run automated scanners against the forms: each submission sends a real email.
